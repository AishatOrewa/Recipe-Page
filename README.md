# Frontend Mentor - Recipe Page Solution

This is my solution to the **Recipe Page** challenge on Frontend Mentor. The project focuses on building a clean and responsive recipe page using semantic HTML and CSS while closely matching the provided design.

## Overview

### The Challenge

Users should be able to:

- View the recipe page on different screen sizes.
- Read the recipe instructions and ingredients easily.
- Experience a clean and responsive layout.

### Links

- **Live Site:** https://aishatorewa.github.io/Recipe-Page
- **Solution URL:** https://github.com/aishatorewa/Recipe-Page

## My Process

### Built With

- Semantic HTML5
- CSS3
- Flexbox
- Mobile-first workflow

### What I Learned

While building this project, I practiced:

- Writing semantic HTML for better accessibility.
- Using Flexbox to structure page elements.
- Creating responsive layouts with CSS.
- Applying spacing, typography, and colors to closely match a Figma design.

### Continued Development

In future projects, I would like to:

- Improve my CSS architecture.
- Learn CSS Grid in greater depth.
- Build more responsive layouts with fewer media queries.
- Continue improving accessibility and code organization.
